# Тестовый стенд расширения

Запуск из корня репозитория: `python tools/extension-preview/serve.py`.

Открыть [dashboard](http://localhost:8766/dashboard.html) или [оверлей](http://localhost:8766/overlay.html). В оверлее нажать группу в синтетическом боковом меню.

Сервер отдаёт текущие исходники расширения без копирования UI. Перед ними подключается подмена Chrome API с 3000 синтетических видео. Изменения существуют только в памяти страницы и сбрасываются при перезагрузке. Доступ к профилю Chrome, токенам и YouTube API отсутствует; manifest и файлы вне разрешённого списка сервер не отдаёт. Ссылки видео/каналов не предназначены для проверки проигрывания.

Проверяемые сценарии: первая порция 60 карточек, Show more, поиск по видео за пределами первой порции, фильтры Unwatched / Liked = watched / Show not interested / Show blocked, меню карточек и переходы управления. Оверлей использует синтетическую оболочку; это не проверка совместимости с реальным DOM YouTube или OAuth.

Проверено во встроенном браузере: dashboard и оверлей создают сначала 60 карточек, Show more увеличивает их число до 120; поиск находит `Demo video 99-29` вне первой порции. Все три дополнительных флага меняют видимость соответствующих тестовых видео. На dashboard отметка просмотра убирает видео при включённом Unwatched; меню скрытия канала работает. Оверлей закрывается кнопкой Close. Нижние действия первых карточек выровнены; на исходной ширине dashboard не имеет горизонтального переполнения. Эти проверки не являются замером производительности настоящего профиля Chrome.

Если локальный сервер запущен внутри сетевой песочницы, встроенный браузер может получать timeout. Для этого запуска потребовалось разрешённое выполнение сервера вне песочницы с привязкой только к `127.0.0.1`; ослаблять firewall или публиковать стенд в интернете не требуется.
