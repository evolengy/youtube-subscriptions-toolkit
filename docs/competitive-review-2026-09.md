# Обзор расширений для YouTube и функций PocketTube (2026‑09)

> Разовый аналитический документ. Задача: пройтись по 11 популярным
> расширениям‑«улучшайзерам» YouTube и по PocketTube, и решить, что из их
> функционала имеет смысл переносить в `desktop-client/`.

## Ограничения нашей архитектуры (фильтр для всех решений ниже)

- **Никаких инъекций в DOM youtube.com.** Это причина существования приложения.
- Воспроизведение по умолчанию — **официальный IFrame Player** (`youtube.com/embed`
  в `Player/player.html`). Он живёт на другом origin → у нас **нет доступа к
  элементу `<video>`, к `<canvas>` без tainting, к chrome плеера**. Доступно только
  то, что даёт IFrame Player API (`postMessage`).
- `Player/player.html` — **наш файл**, туда можно свободно добавлять логику.
- `FullPage`‑режим = немодифицированная watch‑страница (её не трогаем).
- Данные о видео/каналах — только **Data API v3**. Квота 10 000 единиц/день
  (чтение = 1, запись = 50, `search` = 100).
- Community‑посты, транскрипты «владельца», реальная история просмотра —
  **вне Data API v3**.

Легенда вердиктов: ✅ взять · ⚠️ частично / рассмотреть · ❌ не подходит

## Часть 1. Расширения

| # | Расширение | Суть | Вердикт | Что конкретно применимо у нас |
|---|---|---|---|---|
| 1 | **Improve YouTube** | Комбайн из 170+ твиков плеера и UI | ⚠️ | Скорость воспроизведения, повтор/луп, горячие клавиши, фикс. громкость, авто‑качество. **Не берём:** блок рекламы, cinema/ambient, обход региона, PiP из IFrame |
| 2 | **Enhancer for YouTube** | То же семейство: скорость 0.07–16x, буст громкости 10x, тёмные темы, мини‑плеер | ⚠️ | Реверс плейлиста, тонкая настройка автоплея. **Нельзя:** буст громкости >100 % (нужен Web Audio на `<video>`), скрытие end‑screens/cards (chrome плеера cross‑origin) |
| 3 | **YouTube Tags** | Показывает SEO‑теги видео рядом с описанием | ⚠️ нишевое | `snippet.tags` уже приходит в Data API. Добавить в метадату‑строку дёшево, но ценность для зрителя (не креатора) низкая |
| 4 | **AI Summary for YouTube** | Авто‑саммари видео сбоку, копирование транскрипта | ⚠️ рассмотреть | Требует транскрипт (публичный `timedtext`, не Data API) + LLM. Хорошая фича, средний объём, нужен opt‑in + ключ API |
| 5 | **Magic Actions for YouTube** | Комбайн + визуальные фильтры видео (Noir, Oil…), снапшот кадра, mouse‑wheel громкость | ❌ большинство | Эффекты и снапшот в Embed недоступны (canvas tainted). ⚠️ AutoHD (авто‑качество), колесо мыши = громкость в **нашем** chrome |
| 6 | **UnTrap for YouTube** | «Расхламление» YouTube + блок по ключевым словам/каналам + AI‑саммари | ⚠️ | **Ключевая идея:** чёрный список каналов и ключевых слов для ленты. Само расхламление youtube.com нам не нужно |
| 7 | **Custom Progress Bar** | ~1000 косметических скинов полосы прогресса | ❌ | Полоса прогресса — это chrome IFrame‑плеера, cross‑origin. Строить свой оверлей контролов ради скина не окупается |
| 8 | **YouTube List View Mode** | Список вместо сетки, фильтры по длине/дате, блэклист по названию/каналу | ⚠️ | **Взять:** фильтры ленты по длительности (бакеты) и дате загрузки; текстовый поиск/блэклист в ленте. Список↔сетка — у нас уже есть плотность карточек |
| 9 | **YouTube Summary with ChatGPT & Claude** | Саммари + транскрипт с кликабельными таймкодами, выбор языка, свой промпт | ⚠️ рассмотреть (с #4) | Панель транскрипта **без AI** — самостоятельная реализуемая фича. Саммари на базе Claude — надстройка |
| 10 | **YouTube Channel Location** | Бейдж страны канала у описания | ✅ | `Country` уже хранится в `SubscriptionCacheEntry`. Надо просто показать на панели «Channels» и/или в метадату‑строке плеера. Явно указана как вдохновение в `extension/STATUS.md` |
| 11 | **Control Panel for YouTube** | Ещё один комбайн расхламления + блок каналов из контекстного меню + «скрыть просмотренные» + скачать транскрипт | ⚠️ | **Взять:** блок каналов, «скрыть просмотренные» (**уже есть** — `FeedViewModel.HideWatched`), просмотр/скачивание транскрипта |

### Общий вывод по расширениям

8 из 11 — это вариации одного жанра: «почини и расхлами youtube.com + прокачай
плеер». Бóльшая часть их ценности (cinema‑режим, скрытие рекомендаций, блок
рекламы, тёмная тема, кастомный chrome плеера) у нас **либо уже есть, либо не
нужна** — мы не показываем ленту и watch‑страницу YouTube. Переносимое ядро
сводится к небольшому набору (ниже).

## Часть 2. Список фич‑кандидатов (приоритизированный)

### A. Брать — дёшево и вписывается в архитектуру

| Фича | Как | Где |
|---|---|---|
| Скорость воспроизведения | IFrame `setPlaybackRate()` | `player.html` + control в `VideoActionBar` |
| Повтор / луп текущего видео | re‑cue по `onStateChange == ended`, или `playerVars` `loop=1&playlist=<id>` | `player.html` |
| Горячие клавиши плеера | space/k, ←/→, j/l, f, m, ↑/↓, 0–9 → мост в `player.html` | `player.html` + `PlayerView` |
| Бейдж страны канала | данные уже есть (`Country`) | `Views/ChannelManagementPanel`, метадату‑строка |
| Фильтры ленты по длительности и дате загрузки | бакеты поверх `GetVisibleItems` (уже фильтрует по типу) | `FeedViewModel` |
| Текстовый поиск по заголовкам в ленте/группе | ещё один предикат в конвейере `GetVisibleItems` | `FeedViewModel` |
| «Скрыть просмотренные» заметнее в UI | логика уже есть (`HideWatched`), не хватает видимого тумблера | `FeedPanel` |

### B. Рассмотреть — средняя цена, нужна проектная проработка

- **Чёрный список каналов и ключевых слов для ленты** — новая секция в
  `settings.json`, предикат в `FeedViewModel`, пункт «Заблокировать канал» в
  контекстном меню карточки.
- **Панель транскрипта под плеером** — публичный `timedtext`‑эндпоинт,
  кликабельные таймкоды (`seekTo` через мост). Прячется в `FullPage`, как
  комментарии.
- **AI‑саммари видео** — надстройка над транскриптом; opt‑in, ключ API,
  на базе Claude. Отдельный SDD‑спек.
- **Авто‑качество по умолчанию** — `setPlaybackQuality()` работает
  ненадёжно (YouTube часто игнорирует), поэтому «рассмотреть», не «брать».
- **Реверс порядка плейлиста** — у нас есть плейлисты, добавить тумблер.
- **Уведомления по группам** (новое видео → тост/трей) — давний TODO из
  `extension/STATUS.md`, естественно ложится на `BackgroundSyncService` +
  `NotificationCenter`.

### C. Не подходит нашей архитектуре

- Блокировка рекламы (Embed и так почти без рекламы; политика).
- Кастомная полоса прогресса, визуальные фильтры видео, снапшот кадра —
  cross‑origin: нет доступа к `<video>`, canvas tainted в Embed.
- Усилитель громкости >100 % — нужен Web Audio на media‑элементе, недоступен.
- Cinema / theater / ambient, «расхламление» YouTube UI — мы и так отдельный
  плеер, ленту и watch‑страницу YouTube не показываем.
- PiP / pop‑out из IFrame, переключение региона.

## Часть 3. PocketTube — чего у нас нет

| Функция PocketTube | У нас | Комментарий |
|---|---|---|
| Группы подписок | ✅ | есть |
| Лента по группе + сортировка (длина/дата/популярность) | ✅ | есть (нет фильтров по длине/дате — см. Часть 2A) |
| Мульти‑отписка + детект мёртвых каналов | ✅ | есть |
| Отметка «просмотрено» в один клик | ✅ | но **локально**; PocketTube пишет в реальную историю YouTube через DOM |
| **Вложенные группы** | ❌ | группы плоские; иерархия = заметное изменение модели данных |
| **AI авто‑теги каналов** (авто‑категоризация подписок по темам) | ❌ | `channels.list?part=topicDetails` даёт topic‑id — можно маппить в темы |
| **Ручные теги отдельно от групп** + безлимитная фильтрация по тегам | ❌ | у нас только группы |
| **Статус/здоровье канала** на вкладке каналов (активен / спит / частота загрузок) | ❌ | мы отмечаем только полностью «мёртвые»; даты видео для этого уже собираются |
| **Deck** — много‑колоночный режим (колонки = каналы/группы, TweetDeck‑style) | ❌ | новая вью, но переиспользует `VideoCardGrid` |
| **Вкладка Community / посты каналов** | ❌ | **Data API v3 не отдаёт посты сообщества** — только web/scraping, против нашей философии |
| **Кастомные иконки групп** (поиск по 1 000 000 иконок) | ❌ | у нас вообще нет иконок групп |
| **Синхронизация между устройствами** | ❌ | локальный JSON; `settings.json` задуман под будущий sync‑бэкенд |
| Уведомления по группам | ❌ | давний TODO |
| Default tab / режимы видимости / порог «просмотрено» | ⚠️ | частично |
| Мобильные платформы | ❌ | Windows‑only, сознательно |

### Что у нас есть, а в PocketTube нет

- Встроенный плеер (официальный IFrame) — без веб‑входа в YouTube, без квоты на просмотр.
- Тредовые комментарии под плеером + постинг.
- Like / Dislike / Subscribe / Save из приложения.
- Мультиаккаунт с раздельным хранилищем.
- Нативное десктоп‑приложение: тёмная тема, трей, автозапуск.
- Без инъекций в DOM YouTube → на порядок устойчивее к изменениям YouTube.
- ETag‑условный sync + квото‑экономная догрузка глубокой истории.

### Приоритет «догнать PocketTube»

1. **Статус/здоровье канала** на вкладке Channels — данные уже есть, высокая ценность.
2. **Фильтры ленты** по длине/дате + текстовый поиск (Часть 2A).
3. **Теги/вложенные группы** — одна из двух моделей, требует брейншторма.
4. **Deck** — если есть спрос на «мониторинг многих каналов сразу».
5. Community‑посты — **не делать** без отказа от «no‑DOM» принципа.
